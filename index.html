// Background

The Problem We Solved

Hemodialysis patients spend 3–4 hours per session connected to a machine with no physical activity. This leads to muscle atrophy, fatigue, and low morale. We built a solution.

⚕️

Medical Challenge

Patients undergoing hemodialysis remain physically inactive for extended periods, which worsens their overall health condition and reduces treatment efficiency over time.

⚙️

Mechatronic Solution

We designed a physical exercise device with embedded sensors and a web-based monitoring dashboard that tracks patient performance in real time and stores historical session data.

// System Features

What the System Does

A complete end-to-end solution — from hardware sensor reading to web dashboard visualization.

  • Real-time monitoring of APM, speed and exercise intensity
  • Patient registration and individual session history
  • Multi-day performance comparison with charts
  • Web-based admin dashboard via local network
  • Physical LCD display for patient feedback during session
  • Automatic intensity classification (Slow / Medium / Fast)
  • Session statistics and average performance metrics
  • Tested with a real hemodialysis patient over 4 days
