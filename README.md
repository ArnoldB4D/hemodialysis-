# 🏥 Hemodialysis Exercise System
**Sistema Mecatrónico de Ejercicio para Pacientes con Hemodiálisis**

## 📋 Description
Mechatronic prototype designed to help hemodialysis patients perform 
exercise routines during their treatment sessions. The system monitors 
performance in real time and compares results across sessions.

Tested with a real patient over 4 days of continuous monitoring.

## ⚙️ Technologies Used
- Arduino UNO — hardware control and sensor reading
- Hall Effect Sensor — rotation and speed detection
- Neodymium magnets — magnetic pulse detection
- LCD Display 16x2 — local patient interface
- Python + Streamlit — real-time web monitoring dashboard
- Encoder motors — force and velocity measurement

## 🔧 System Features
- Real-time monitoring of speed, rhythm and exercise intensity
- User registration and session history
- Multi-day performance comparison charts
- Web-based admin dashboard
- Local physical display for patient feedback
